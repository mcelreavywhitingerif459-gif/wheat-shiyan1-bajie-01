# 2.6 wheat bajie 01

This public repository contains only the Pix4D project data from `2.6 wheat bajie 01`.

The source folder contains 4,003 files. They are packaged into 16 ZIP volumes attached to the `v1.0.0` release. Download all 16 volumes, then extract them into the same destination folder. Archive paths are stored under `wheat-shiyan1/`.

The separate `2.6 wheat bajie 02` dataset is not included in this public repository.
